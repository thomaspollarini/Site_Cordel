# Cordel Moderno - Site em HTML e CSS

Este projeto é um site simples desenvolvido com **HTML** e **CSS**, relatando a poesia de Milton Duarte. O objetivo é praticar a estruturação de páginas web e a aplicação de estilos básicos.

## Sobre o projeto

O site apresenta uma poesia de Milton Duarte, utilizando apenas tecnologias front-end puras, sem frameworks ou bibliotecas externas.  
O projeto serve como prática para:

- Estruturação semântica de HTML5
- Estilização com CSS3
- Organização de conteúdo em uma página web

## Tecnologias utilizadas

- HTML5
- CSS3
